# Maxwell Borotho: Meet Our Founder

    index.html          Built page (open this, or link to it from the "Meet Our Founder" button)
    build.py            Rebuilds index.html from sections/  (python build.py)
    sections/           One HTML file per section, in page order
    css/                Styles split by area (base, nav, hero, content, projects, journey, company, responsive)
    js/                 Behaviour split by job (site, reveal, nav, contact)
    images/founder.jpg  Add your photo here (falls back to the "MB" monogram if missing)

Edit a section file, then run `python build.py`. If you would rather not run Python,
edit index.html directly; the CSS and JS files work the same either way.
